Guide for Xiaomi MIUI 14

Follow these steps to prevent the system from killing the app in background.

1

Access Battery Settings

Go to Settings > Battery & Performance.

2

Find App Saver

Tap the gear icon settings in the top right, then select App battery saver.

play_arrow
3

Select Xpenzo

Search or scroll to find Xpenzo in the app list.

4

Remove Restrictions

Select No restrictions. This is crucial for consistent tracking.
